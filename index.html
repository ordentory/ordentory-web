Why Inventory

엑셀은 복잡해졌지만,
ERP까지는 필요하지 않을 때.

첫 번째 모듈인 Inventory는 소규모 사업자의 재고 흐름에 집중합니다. 필요한 기능은 연결하고, 불필요한 복잡함은 줄였습니다.

업무 순서 그대로,
화면도 이어집니다.

Practical Tools

반복되는 재고 업무도,
더 빠르고 안전하게.

단순히 재고를 기록하는 데서 끝나지 않습니다. 실사, 바코드 입출고, 대량 등록과 백업처럼 실제 운영에서 자주 반복되는 업무까지 이어집니다.

재고실사

스캔→SKU 확인→수량 확정→원장 생성
03
IMPORT

파일 선택→미리보기→오류 확인→가져오기

Core Features

재고관리에서
자주 쓰는 것에 집중했습니다.

01

상품 · SKU

상품, 옵션, SKU 코드, 바코드, 카테고리와 안전재고를 구조적으로 관리합니다.

02

재고 · 입출고

현재재고와 입고·출고·조정 원장을 함께 확인해 수량 변화의 근거를 남깁니다.

03

공급처 · 발주

SKU별 공급처와 매입정보를 연결하고 안전재고 기준으로 발주와 입고예정을 관리합니다.

04

데이터 · 백업

재고 데이터를 Excel·CSV로 활용하고 지정 위치에 백업해 데스크톱 데이터를 안전하게 관리합니다.

For Small Business

엑셀보다 체계적이고,
ERP보다 가볍게.

ORDENTORY는 필요한 업무부터 모듈로 확장하는 Windows 프로그램입니다. 첫 번째 모듈 Inventory는 상품과 재고, 입출고, 공급처와 발주가 복잡해지기 시작한 사업자를 위한 제품입니다.

✓
SKU가 늘어나기 시작한 판매자엑셀 행과 시트가 늘어날수록 관리가 어려워졌다면.
✓
현재고와 입출고 이력을 함께 보고 싶은 사업자숫자 하나가 아니라 재고가 변한 이유까지 확인하고 싶다면.
✓
공급처와 발주까지 연결하고 싶은 운영팀재고 부족 확인부터 실제 입고까지 한 흐름으로 관리하고 싶다면.

FAQ

구매 전에
자주 묻는 질문.

ORDENTORY는 어떤 프로그램인가요?
ORDENTORY는 필요한 업무를 모듈별로 확장하는 Windows 데스크톱 소프트웨어입니다. 현재 제공되는 첫 모듈 Inventory에서 상품·SKU, 재고, 입출고, 공급처, 발주와 부분입고를 관리할 수 있습니다.
ERP를 대체하는 프로그램인가요?
현재 판매 중인 Inventory 모듈은 회계·인사·생산 등 모든 경영영역을 포함하는 ERP가 아니라, 소규모 사업자의 재고관리 업무에 집중한 제품입니다. 이후 다른 업무 모듈은 별도로 추가될 수 있습니다.
Excel이나 CSV로 데이터를 내보낼 수 있나요?
네. 현재재고와 입출고·재고원장을 검색/필터 조건에 맞춰 Excel 또는 CSV로 저장할 수 있으며, 기간별 입출고 요약도 Excel 보고서로 저장할 수 있습니다. 상품은 ORDENTORY Excel 양식을 이용해 대량으로 가져올 수 있습니다.
데이터 백업은 가능한가요?
네. 수동 백업과 복원을 지원하고, 사용자가 지정한 폴더에 정기 자동백업을 만들 수 있습니다. OneDrive 동기화 폴더·외장 저장장치·NAS 동기화 폴더처럼 현재 데이터와 다른 위치를 지정하는 방식을 권장합니다.
라이선스는 몇 대의 PC에서 사용할 수 있나요?
Inventory 정식 라이선스 1개는 1개 사업체 기준 최대 2대의 PC에서 사용할 수 있습니다. 3번째 PC에서는 기존 장치를 해제한 뒤 활성화할 수 있으며, 정상적인 PC 이전 횟수에는 별도 제한을 두지 않습니다. 각 PC의 업무 데이터는 로컬에 저장되며 기본 라이선스에 PC 간 자동 동기화는 포함되지 않습니다.
다른 모듈도 개발하나요?
Inventory는 ORDENTORY의 첫 번째 모듈입니다. Sales·Order·Label 등은 향후 확장 방향이며, 현재 판매하는 Inventory 라이선스에 포함되지 않습니다. 출시 시점·기능·가격은 별도 공지합니다.
무료 체험이 있나요?
네. 자사몰에서 이메일 인증을 완료하면 Inventory 7일 무료체험 코드가 발급됩니다. 코드와 설치파일 다운로드 링크는 인증된 이메일로도 보내드립니다. 최초 PC 활성화 시점부터 7일이며 체험판은 1대의 PC에서 사용합니다.
업데이트 비용은 어떻게 되나요?
Inventory v1.x 범위의 업데이트는 정식 라이선스 구매자에게 추가 비용 없이 제공합니다. 향후 v2.x처럼 메이저 버전이 변경되는 경우에는 별도 유료 업그레이드 정책을 적용할 수 있으며, 출시 전에 가격과 조건을 안내합니다.
PC를 바꾸거나 고장 나면 라이선스를 다시 살 필요가 있나요?
아니요. 정상적으로 사용할 수 있는 기존 PC에서는 장치를 직접 해제한 뒤 새 PC에서 다시 활성화할 수 있습니다. 기존 PC가 고장·분실되어 직접 해제할 수 없는 경우에는 고객지원에서 확인 후 장치를 강제 해제합니다.
구매 후 무엇을 받게 되나요?
자사몰 결제가 오픈되면 결제 완료 즉시 구매 이메일로 정식 라이선스 코드, 서명된 ORDENTORY 설치파일 다운로드 링크, 사용자 매뉴얼과 라이선스 활성화 방법을 자동 안내합니다.
구매와 라이선스 발급은 어떻게 진행되나요?
자사몰 결제 기능은 현재 오픈 준비 중입니다. 결제 오픈 후에는 서버에서 결제 완료를 검증한 뒤 ORDENTORY Inventory 영구 라이선스를 자동 발급하는 흐름으로 제공됩니다.
