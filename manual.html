ORDENTORY INVENTORY v1.0.0

설치 및 사용자 매뉴얼

구매 후 받은 라이선스 코드와 구매 이메일로 ORDENTORY를 활성화할 수 있습니다. 설치파일에는 공식 사용자 매뉴얼과 빠른 시작 안내서가 함께 포함됩니다.

ORDENTORY 설치파일 다운로드 이메일 문의

1. 설치

  1. 위 버튼에서 ORDENTORY_Setup.exe 다운로드
  2. Windows에서 설치파일 실행
  3. 게시자 및 코드서명 확인 후 설치 진행
  4. 설치가 끝나면 ORDENTORY 실행

2. 라이선스 활성화

  1. [라이선스] 메뉴 이동
  2. 구매 이메일과 라이선스 코드 입력
  3. 이메일로 받은 6자리 인증번호 입력
  4. 활성화 완료 후 Inventory 사용

3. 공식 PDF 매뉴얼

설치 후 ORDENTORY 설치 폴더의 docs에서 공식 문서를 확인할 수 있습니다.

docs\ORDENTORY_User_Manual.pdf
docs\START-HERE.pdf

4. 라이선스 정책

  • 1개 사업체 / 최대 2PC
  • 영구 사용권
  • v1.x 업데이트 무료
  • PC 이전 시 기존 장치 해제 후 새 PC 활성화
  • 고장·분실 시 고객지원에서 강제 해제 지원
