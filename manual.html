01. OFFICIAL DOCUMENTATION

공식 사용자 매뉴얼

매뉴얼을 포함한 개선된 정식 설치 패키지에서는 설치 후 프로그램의 [도움말] 화면에서 공식 사용자 매뉴얼(PDF)과 빠른 시작(PDF)을 열 수 있습니다.

설치 위치

ORDENTORY 설치 폴더 → docs → ORDENTORY_User_Manual.pdf, START-HERE.pdf

ORDENTORY 설치파일 받기 공식 PDF 매뉴얼 다운로드

온라인 PDF는 승인된 최종 매뉴얼이 게시되면 다운로드 버튼이 표시됩니다. 설치본에는 승인된 매뉴얼만 포함합니다.

02. GET STARTED

처음 사용하는 순서

설치

  1. 위 공식 설치파일을 다운로드하고 실행합니다.
  2. ORDENTORY 실행 후 [라이선스] 화면으로 이동합니다.

7일 무료체험

  1. 평가판 안내 이메일의 Trial 코드를 입력합니다.
  2. [7일 무료체험 라이선스 활성화]를 선택합니다.
  3. 최초 PC 활성화 시점부터 7일이 시작되며, PC 1대에서 사용할 수 있습니다.

정식 구매

  1. 구매용 라이선스 코드와 구매 시 등록한 이메일을 입력합니다.
  2. [이메일 인증번호 발송] 후 구매자 메일로 수신한 6자리 인증번호를 확인합니다.
  3. [인증번호 확인 및 PC 활성화]를 완료합니다. 정식판은 1개 사업체 기준 최대 PC 2대입니다.

첫 재고 입력

공급처 등록 → 상품 등록 → SKU/옵션 설정 → 초기재고 입력 → 안전재고 설정. 발주완료만으로는 현재고가 증가하지 않으며, 실제 입고 처리한 수량만 현재고에 반영됩니다.

중요한 변경이나 업데이트 전 [데이터 보관] → [백업 파일 저장]을 권장합니다. 오류가 발생해도 고객 데이터 폴더를 임의 삭제하지 마세요.
